Parking SV — Python Desktop Prototype
====================================

This package contains a desktop prototype for Parking SV built with Python,
BeeWare Toga and Briefcase.

The application creates a Toga window and loads the packaged HTML interface
from the resources directory into a Toga WebView. The HTML resource contains
the interface, styling and JavaScript navigation between sample screens.

The prototype demonstrates desktop/web-view integration and a parking
discovery interface. Parking listings and profile content are predefined
examples; authentication, reservations, payment processing and live parking
availability are not connected to a backend.

The repository-level README documents the interface, implementation,
prototype limitations and development setup in English and Spanish:
https://github.com/parkingSV26/PARKING-SV_PYTHON-
