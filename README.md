## About this repository

This repository is the Python project space associated with Parking SV. It is separate from the Next.js web application and has its own source history.

The public web demo is the recommended starting point for visitors who want to explore Parking SV online. The Python source repository is provided as a separate codebase for technical reference.

## Setup and execution

The exact installation and launch commands depend on the entry point and dependencies present in this repository. Review the source files and dependency manifests before running it. Do not assume that the Next.js instructions apply to this Python codebase.
